Abyssal Assault

Game I made for a game jam in a few hours. It was a ton a fun and the first game I didn't use tutorials/AI to make.

The theme of the game jam was "water", with "health" as prerequisite, so I decided to make the player more agile when losing more health.

It's just a quick demo. Downloading the game takes longer than beating it.

Currently only available for Windows.
